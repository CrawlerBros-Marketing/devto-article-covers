# crawlerbros-devto-covers

Public 1000x420 cover images for CrawlerBros dev.to articles, one per Apify Actor,
keyed by Actor slug: `covers/<actor-name>.png`.

dev.to's homepage hero slot is hard-gated on `main_image IS NOT NULL`
(`FindFeaturedStory.call(stories, must_have_main_image: true)`), and 1000x420 is the
documented cover spec. Generated by `_audit/make_covers.py` in the publishing repo.
